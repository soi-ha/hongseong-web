# 홍성 아이디어북

Astro + TypeScript 기반 내부 검토용 정적 사이트. 제안 PPT v03의 30쪽 배치를 바탕으로 표지·클로징에 디자인 가이드 v16을 반영하며 전체 화면 발표를 지원한다. ‘출처’ 버튼을 누르면 현재 슬라이드의 관련 링크·사진 출처·원문 주석을 모달로 열람한다. 별도 본문 페이지로 전환하지 않는다. 30쪽은 v03 클로징이며 자료조사 페이지는 준비 중이다.

‘아이디어’는 카드 목록과 별도 상세 페이지로 구성했다. 현재는 궁리 1박 코스·홍성 1박 패스·궁리항 월별 브랜드 모임의 예시3개만 제공하며, 상세마다 사진2장·아이디어 설명·진행 흐름·검토할 내용·관련 제안서 링크를 표시한다.

사이트 이름은 2026-10-24 사용자 선택에 따라 **홍성 아이디어북**으로 통일했다. 이름은 `src/config/site.ts`에서 관리하며 헤더와 브라우저 탭에 사용한다. 탭은 `제안서 | 홍성 아이디어북`, `아이디어 | 홍성 아이디어북`, `자료조사 | 홍성 아이디어북`, 상세는 `아이디어 제목 | 홍성 아이디어북` 형식이다. 제안서 본문 제목은 그대로 보존한다.

아이디어 예시는 `src/content/ideas.ts`에서 편집한다. 사진은 기존 `proposal-photos.json`의 키를 연결해 출처·제공자·사용권 기록을 재사용하며 이미지를 중복 복사하지 않는다. 상세의 사진은 원본 비율을 유지하고, 카드 썸네일은3:2 프레임의 하단 기준으로 표시한다. 예시 내용은 기존 v02 제안서의 해당 절을 요약한 검토용 문구이며 원문과 자동 동기화되지 않는다. 원문 개정 시 관련 예시와 조건을 함께 대조한다. 등록·수정용 관리자 화면은 없으며 추가 예시 제작은 후속 요청 범위다.

목차는 제안 개요 → A안 코스 → A안 운영 → A안 성과·협의 → B안 구성 → B안 운영·성과 → 비교·추진 → 근거·조건으로 구성했다. 하단 왼쪽에는 현재/전체 쪽수와 ‘출처’, 오른쪽에는 전체 화면·이전·다음을 배치했다. 중앙 선택 상자는 제거했으며 하단 여백은 데스크톱32px·모바일24px에 기기 안전 영역을 더한다. 내부 목차는 해당 시작 쪽으로 이동한다. `#page-16` 같은 직접 링크·새로고침·뒤로/앞으로 가기를 지원하며 처음·끝 방향 버튼은 비활성화한다.

전체 화면 버튼 또는 `F`로 발표를 시작하고 `Esc`로 종료한다. `←`/`→`, `PageUp`/`PageDown`으로 이동하고 `Home`/`End`로 처음/마지막 쪽에 간다. 발표 중 `↑`/`↓`와 `Space`/`Shift+Space`도 지원한다. 발표 모드에서는 사이트 메뉴가 숨겨지고 조작부는2.2초 뒤 자동으로 숨는다. 포인터 이동·키보드 포커스로 다시 표시된다. 전체 화면을 지원하지 않거나 거절된 환경은 안내 후 창 안 발표 모드로 전환한다. [Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)의 사용자 동작 요구와 `fullscreenchange` 이벤트를 따른다.

슬라이드는16:9 전체 화면을 함께 확대·축소하여 원본 배치를 유지한다. ‘출처’는 현재 페이지의 링크와 주석만 담은 모달을 연다. 링크는 새 탭에서 열린다. 외부 링크나 참고·확인 사항이 없으면 해당 항목의 제목·빈 상태 안내·구분선을 표시하지 않는다. 구분선은 실제 내용이 있는 항목 사이에만 표시한다. 닫기 버튼·Esc·바깥 영역 클릭으로 닫으며 같은 슬라이드와 출처 버튼 포커스로 돌아온다. 모달 안에서만 Tab 포커스가 순환하고 방향키·Home/End·F는 뒤쪽 슬라이드를 조작하지 않는다. 모달은 최대640px 높이로 제한하며 작은 화면에서는 화면 높이에서 바깥 여백을 뺀 크기로 줄인다. 제목·닫기 버튼은 고정하고 긴 출처 내용만 내부에서 스크롤한다. 링크 버튼은72px 높이로 통일하고 제목은 최대2줄, 도메인은1줄로 표시한다. 긴 이름의 전체 문구는 링크의 접근성 이름과 툴팁에 보존한다. 두 높이는 `global.css`의 공통 변수로 관리한다. 전체 화면에서도 사용할 수 있도록 모달은 발표 영역 내부에 둔다. JavaScript가 꺼져 있으면 슬라이드만 이어서 표시하며 페이지 넘기기·출처 모달은 사용할 수 없다. Astro 개발 도구 모음은 비활성화했다.

텍스트 기준은 기존 홍성 프로젝트의 `문서/261023_홍성_관광객유치_제안_A안·B안_v02.md`. 복사본 SHA-256: `13941d277ec2d0a2bd8d1c0f6d92bd92bfca03d718972573377d104f917c10ce`. 이번 사용자 요청으로 시각 기준은 같은 문서 폴더의 최종 `261023_홍성_관광객유치_제안_A안·B안_v03.pdf`로 변경했다. v02→v03의29쪽 문구·수치·사진·발표자 노트는 현재 PPT XML·사진 해시 대조에서 동일하며 클로징만30쪽에 추가되었다. 중간 작업본 `native-qa.pdf`는 최종 PDF와 달라 사용하지 않는다. 원본 PPT/PDF·기존 자료는 수정하거나 저장소에 전체 복사하지 않았다.

최종 PDF 해시 `b4f2da32468aae76ad304176f66b3c5d3e6d89285791ed7751ff323ab57977f2`, PPT 해시 `f8bf0632e1b36149eadfd952f19dc7ce4037be68e04b6ebbf42b7ee3c1cbc82f`. 720×405pt 원본을3840×2160px 무손실 WebP로 변환하여30장 합계14,334,010바이트를 제공한다. 표지·클로징만 아래 v16 제외 규칙을 적용했으며 나머지28장은 기존 변환본과 해시가 같다. 변환 전후 디코딩 픽셀 일치 확인. 임시 Python 환경의 PyMuPDF1.26.5·Pillow11.3.0만 사용하며 npm 의존성은 변경하지 않았다. 현재 쪽과 인접 쪽부터 로드한다. 슬라이드 화면 자체는 이미지이며 편집 가능한 HTML 객체가 아니다. 내용 개정 시 원본과 텍스트 복사본을 함께 대조하고 슬라이드를 다시 변환한다.

## 웹 디자인 적용

가이드 v15로 제작한 PPT v03의 페이지별 조판을 바탕으로, 최신 v16 요청에 따라 표지·클로징의 상단 문서명·날짜·하단 조건 주석을 제외한다. 표지·클로징의 쪽수 생략은 유지하며 제목·부제·사진·재생 모티프·배치는 보존한다. 조건 설명은 출처 모달에 유지한다. 2~15쪽은 흰색, 16~29쪽은 다크, 1쪽 표지와30쪽 클로징은 승인된 어두운 사진 처리다. 사진의 프레임·크롭·워터마크, 표의 열폭·선·정렬, 나머지 글자 크기·굵기·자간을 PDF 출력 그대로 보존한다. 일반 보기의 슬라이드 바깥 여백·하단 조작부·사이트 메뉴·내부 목차는 기존 웹 배경인 흰색으로 고정한다. 페이지 테마는 슬라이드 이미지에만 적용하며 출처 모달은 항상 밝은 배경으로 표시한다.

일반 보기의 슬라이드는 기존 화면 맞춤 크기에서 가로·세로를 각각80%로 줄여 중앙 배치한다. 실제16:9 슬라이드 경계에 그림자 `0 8px 24px rgb(0 0 0 / 15%)`를 적용하며 모서리 형태는 원본 그대로 유지한다. 전체 화면과 창 안 발표 모드는 여백을 검정 `#000000`으로 고정하고, 슬라이드는 그림자 없이 기존 최대 화면 맞춤 크기로 표시한다. 공통 변수 `--slide-preview-scale`, `--shadow-slide`, `--color-presentation-surround`에서 관리한다.
